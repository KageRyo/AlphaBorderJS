# AlphaBorderJS

AlphaBorderJS is a simple web tool for generating luma key transparency and glowing stroke effects on images with a black background. Just drag and drop your image, adjust the sliders, and export the result as a PNG.

## Features
- Luma keying (removes black background)
- Adjustable stroke width and glow radius
- Custom glow color
- Live preview
- Export as PNG (keeps original image size)
- All UI in Traditional Chinese

## Usage
1. Open `index.html` in your browser (use a local server for best results).
2. Drag and drop an image with a black background into the drop zone, or click to select a file.
3. Adjust the luma threshold, stroke width, glow radius, and color as needed.
4. Click "匯出 PNG" to download the processed image.

## Notes
- Works best with images that have a pure black background.
- Exported PNG will include padding for glow/stroke effects.
- No image is uploaded to any server; all processing is local.
